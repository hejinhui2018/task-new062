# GrantKit 盲审材料工作台

面向公益机构奖学金评审的纯前端工作台：导入申请材料与评分规则后，系统自动生成**匿名评审包**，按规则计算**资格与分项得分**，并明确指出**缺失证据、重复材料、规则冲突**与每条得分的触发依据。全部数据保存在浏览器 localStorage，刷新后可恢复。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm test         # 运行测试（vitest，38 个用例）
npm run build    # 类型检查 + 生产构建
```

## 功能

- **导入**：粘贴申请材料 / 评分规则 JSON，结构校验失败会给出中文错误定位；也可一键载入内置示例。
- **匿名评审包**：按规则包 `piiFields` ∪ 字段 `pii` 标记移除 PII 字段，并对正文做值替换 + 邮箱/手机号/身份证号模式脱敏；匿名编号 = hash（申请人 ID + 轮次盐值），每轮不同。
- **可解释评分**：每条资格/评分规则展示条件、实际值、判定、得分；触发但缺证据的评分项被拦截并注明；类别分数超上限时显示「原始分 → 封顶」。
- **问题检测**：缺失证据清单、重复材料（规范化内容哈希分组）、规则冲突（重复 ID / 矛盾门槛 / 负分 / 悬空上限）。
- **评审操作**：切换评审轮次（各轮标记独立）、手工标记证据「有效/存疑」（存疑证据不计入评分证据池）、撤销/重做（Ctrl+Z / Ctrl+Shift+Z）、命名快照与恢复（恢复本身可撤销）、导出当前轮次的匿名评审包 JSON。
- **内置三份有意缺陷的申请**：
  - `APP-2026-001`：文书与证据混入姓名/邮箱/手机号/身份证号；声称志愿 120 小时但缺志愿证明（S3 被拦截）；学业分触发类别封顶。
  - `APP-2026-002`：GPA 恰好 3.2、志愿恰好 100 小时（规则边界）；成绩单重复提交；家庭年收入超资格线。
  - `APP-2026-003`：缺少 `fullTime` 字段（按「字段缺失」判不通过并说明）；推荐信中留有推荐人手机号（模式脱敏）。

## 设计要点

- **匿名化与字段顺序无关**：PII 判定按 key 匹配，输出字段按 key、证据按 id 规范化排序，匿名编号只依赖申请人 ID 与轮次盐值——测试中对字段/证据做确定性置换后结果深度相等。
- **可解释**：`evaluate()` 返回完整的条件轨迹（期望值/实际值/未通过原因）、被拦截评分项及原因、类别封顶明细。
- **本地持久化**：每次变更即写入 `localStorage`（键 `grantkit-workbench-v1`，含版本号），刷新后恢复会话、标记、快照与撤销历史；存储损坏或版本不匹配时安全回退到内置示例。

## 测试（tests/）

| 文件 | 覆盖 |
| --- | --- |
| `rules-boundary.test.ts` | 门槛恰好取等/差一点、类别封顶、字段缺失、类型不匹配、各操作符、规则冲突检测 |
| `duplicates.test.ts` | 重复材料检出、空白/大小写规范化、不误报、多份同组 |
| `missing-evidence.test.ts` | 触发但缺证据被拦截、补齐后解除、资格证据缺失、「存疑」标记剔除证据 |
| `anonymize.test.ts` | PII 字段移除、文本脱敏、字段/证据顺序无关、编号稳定性与轮次隔离 |
| `history.test.ts` | 撤销/重做、快照保存/恢复/删除、刷新后完整恢复、损坏存储回退、轮次标记隔离 |
